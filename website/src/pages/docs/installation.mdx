## Install the extension

Use the Better Playwriter listing in Chrome Web Store once available. For a preview, get the extension ZIP from this project's GitHub Releases or build it from source. Extract it, open `chrome://extensions`, enable **Developer mode**, and select **Load unpacked** to choose the extracted folder.

For a local build, run `pnpm bootstrap` and `pnpm build` from the repository root, then select `extension/dist` in Chrome. Building from source requires Git, Node.js, pnpm, and Bun.

## Install the CLI

Once the npm package is published:

```bash
npm install -g better-playwriter
```

In a built source checkout, run `npm link` from `playwriter/` or run `node ./playwriter/bin.js` from the repository root.

## Connect a tab

Open a tab and click the Better Playwriter icon. Start `better-playwriter session new --tab-group docs` to launch the relay. The icon turns green when the tab connects. Continue with the [quick start](./quick-start.mdx).

For a fresh browser with the extension bundled, run `better-playwriter browser start`. It uses Chrome for Testing or Chromium. For tests without a browser window, see [headless mode](./headless.mdx).

## Load the agent skill

Run `better-playwriter skill` for the core workflow. Open a topic with `better-playwriter skill --ref snapshots`. See the [skill guide](./skill.mdx) for automatic discovery on a configured docs site.
