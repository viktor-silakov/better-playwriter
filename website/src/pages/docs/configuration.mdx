Better Playwriter is configured through **CLI flags** and **environment variables**. No config files needed.

## Environment variables

| Variable | Description | Default |
|---|---|---|
| `BETTER_PLAYWRITER_PORT` | Local relay port. Set the same value when building the unpacked extension. | `19989` |
| `BETTER_PLAYWRITER_DATA_DIR` | Directory for local settings, logs, recordings, and downloaded browsers. | `~/.better-playwriter` |
| `BETTER_PLAYWRITER_HOST` | Address of a remote relay you control. | Local relay |
| `BETTER_PLAYWRITER_TOKEN` | Authentication token for remote connections. | Unset |
| `BETTER_PLAYWRITER_EXEC_TIMEOUT` | Execution timeout in milliseconds. | `10000` |
| `BETTER_PLAYWRITER_REMOTE_URL` | Compatible browser-sharing service endpoint. | Unset |

Existing `PLAYWRITER_*` variables have lower precedence than the corresponding fork variables. To reuse the old data directory, stop its relay first and point `BETTER_PLAYWRITER_DATA_DIR` at `~/.playwriter` explicitly. The fork normally keeps its files separate.

For token-protected connections, use a trusted relay URL and set `BETTER_PLAYWRITER_TOKEN` through your environment. See [remote access](./remote-access.mdx).

## CLI global flags

| Flag | Description |
|---|---|
| `-s, --session <id>` | Session ID (required for `-e`, `-f`) |
| `-e <code>` | Execute JavaScript code inline |
| `-f <path>` | Execute JavaScript from a file |
| `--host <host>` | Remote relay server host |
| `--token <token>` | Auth token for remote connections |
| `--timeout <ms>` | Execution timeout (default: 10000) |

## Session new flags

| Flag | Description |
|---|---|
| `--browser <key>` | Browser type: extension ID, `headless`, `direct:port` |
| `--direct [endpoint]` | Direct CDP: auto-discover or explicit endpoint |
| `--patchright` | Connect with Patchright and human-like input. Switch later with `session update <id> --patchright`. See [sessions](./sessions.mdx#patchright) |

## Browser start flags

| Flag | Description |
|---|---|
| `--user-data-dir <dir>` | Persistent profile directory |
| `--headless` | Headless mode |
| `--headed` | Show browser window |
| `--disable-sandbox` | Disable Chrome sandbox |

## Serve flags

| Flag | Description |
|---|---|
| `--host [host]` | Bind host (default: `0.0.0.0`) |
| `--token <token>` | Auth token (required for public hosts) |
| `--replace` | Kill existing server on the port |

## MCP configuration examples

### Basic (extension mode)

```json
{
  "mcpServers": {
    "better-playwriter": {
      "command": "npx",
      "args": ["-y", "better-playwriter@latest"]
    }
  }
}
```

### Direct CDP and cloud browser providers

There is no MCP config for these. The agent calls the `session_new` tool with `direct: "auto"` to find Chrome with debugging on, or with an endpoint like `wss://browser.example.com`. See [MCP setup](./mcp-setup.mdx).

### Remote relay

```json
{
  "mcpServers": {
    "better-playwriter": {
      "command": "npx",
      "args": ["-y", "better-playwriter@latest"],
      "env": {
        "BETTER_PLAYWRITER_HOST": "https://relay.example.com",
        "BETTER_PLAYWRITER_TOKEN": "MY_SECRET"
      }
    }
  }
}
```

## Debugging configuration

Better Playwriter logs to files for debugging:

```bash
# Get log file paths
better-playwriter logfile
# typically: ~/.better-playwriter/relay-server.log

# CDP JSONL log for protocol debugging
jq -r '.direction + "\t" + (.message.method // "response")' ~/.better-playwriter/cdp.jsonl | uniq -c
```

Both files are recreated every time the relay server starts.
