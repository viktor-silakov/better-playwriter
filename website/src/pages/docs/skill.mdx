Run `better-playwriter skill` for the core workflow. Run `better-playwriter skill --ref snapshots` for a topic reference. In a built source checkout, use `node ./playwriter/bin.js` from the repository root.

If you host the docs site, its [skill discovery index](/.well-known/skills/index.json) advertises the `better-playwriter` skill and its downloadable entrypoint. The [core instructions](/SKILL.md) link to the available topic references.
