Run `better-playwriter skill` from an installed CLI. In a built source checkout, run `node ./playwriter/bin.js skill` from the repository root.

If you host the docs site, its [skill discovery index](/.well-known/skills/index.json) advertises the `better-playwriter` skill and its downloadable entrypoint. You can also use the [full instructions](/SKILL.md) directly.
