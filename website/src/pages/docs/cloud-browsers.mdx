Better Playwriter uses local Chrome by default. The `cloud` commands need a compatible service explicitly configured with `BETTER_PLAYWRITER_CLOUD_URL`. For device login, `better-playwriter cloud login --base-url <url>` can set the service URL.

Use credentials issued for that endpoint. For a test that only needs a clean browser, see [headless Chrome](./headless.mdx). For a remote Chrome instance you already control, see the [direct CDP options](./cli.mdx).
