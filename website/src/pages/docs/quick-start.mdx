[Install the CLI and extension](./installation.mdx), then click the Better Playwriter extension icon on a Chrome tab. The icon turns green when the local relay connects.

## Start, observe, and clean up

```bash
better-playwriter session new --tab-group docs
better-playwriter -s 1 -e 'state.page = await context.newPage(); await state.page.goto("https://example.com")'
better-playwriter -s 1 -e 'console.log(await snapshot({ page: state.page }))'
better-playwriter session delete 1 --close-created-tabs
```

Use the session ID printed by the first command instead of `1`. Store the tab in `state.page` to reuse it between commands. Read a fresh snapshot after interacting with the page to verify what changed.

Use `--release-created-tabs` instead of `--close-created-tabs` when you want to keep the tabs open and remove them from the session's group.

## Choose your setup

- `better-playwriter skill` prints the agent instructions.
- The [MCP guide](./mcp-setup.mdx) shows how to configure an MCP client.
- [Headless Chrome](./headless.mdx) runs tests without using your usual profile.
- `better-playwriter session new --direct` connects to a Chrome instance with DevTools Protocol already enabled.
