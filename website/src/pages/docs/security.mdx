The default relay listens on `127.0.0.1:19989`. Chrome tabs become available when the user enables them with the extension icon or a session opens them. The extension uses Chrome's debugging banner and toolbar icon to show which tabs are connected.

## Session scope

Each session has its own `state`. It sees tabs created by the session and tabs shared by the user. To reduce the data available to automation, select a dedicated browser profile or use [headless Chrome](./headless.mdx). Review logs and recordings locally, since they can contain private browser data.

## Optional remote access

[Browser sharing](./remote-control.mdx) requires a configured tunnel service and confirmation from the user. Share links give broad browser access until they are revoked. Keep them private.

For [access to a relay you run](./remote-access.mdx), configure an authentication token and use a trusted network or transport. Pass secrets as environment variables and keep them out of version control and screenshots.

## Recordings and tab data

Record only authorized tabs. Generated workflows, recordings, and snapshots can contain browser data. Strip personal names, account details, credentials, and private URLs before sharing them. See [Privacy](../privacy.mdx) for details.
