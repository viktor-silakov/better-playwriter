## Local browser data

Better Playwriter runs the browser relay on your device by default. The extension sends data from enabled tabs to the local relay so clients can run browser commands and receive results. Data can include URLs, page content, screenshots, input events, and network details, depending on the commands you run.

The extension uses a random local installation ID and may read your Chrome profile name or account email to help distinguish connected profiles. You can set a profile label in extension settings. The local relay can store logs, recordings, and profile labels on your device. `better-playwriter logfile` lists the log locations. Usage telemetry is off by default.

## Optional external connections

A managed cloud browser requires a service URL and credentials. If a tunnel service is configured, confirming **Remote control** lets a recipient operate your enabled tabs and open new tabs. The remote recipient and the service operator can handle browser data or connection metadata. Access ends when you choose **Stop sharing**, close or detach the sharing tab, or close Chrome. Check the configured provider's policy before sending browser data outside your device.

You can also configure a direct connection to a relay you run. Use authentication and a trusted transport.

## Controls

Click the extension icon again to detach an enabled tab. Manage local logs and recordings in the data directory. Remove the extension in Chrome to clear its extension storage.

For a privacy or security report, contact the project's maintainer privately. Include a minimal description with synthetic examples and keep personal information and credentials out of reports.
