Better Playwriter connects the Chrome tabs you enable to a local relay. Use the CLI, MCP server, or Node.js SDK to run Playwright commands. The browser keeps its existing profile and extensions.

## Start a session

[Install Better Playwriter](./docs/installation.mdx) and enable the extension on a tab. Then run:

```bash
better-playwriter session new --tab-group docs
better-playwriter -s 1 -e 'state.page = await context.newPage(); await state.page.goto("https://example.com")'
better-playwriter -s 1 -e 'console.log(await snapshot({ page: state.page }))'
```

Replace `1` with the session ID printed by the CLI. Use the same ID to keep `state.page` between commands. [Quick start](./docs/quick-start.mdx) walks through a complete example.

## Data and access

The relay runs on `127.0.0.1:19989` by default. For testing without a personal profile, use [headless Chrome](./docs/headless.mdx). See [Security](./docs/security.mdx) and [Privacy](./privacy.mdx) for browser data and optional remote connections.

Better Playwriter is a fork of [Playwriter](https://github.com/remorses/playwriter).
