Open or activate tabs in a verified macOS Chrome profile with `better-playwriter browser open`.

Get shorter interactive snapshots by default, with compact reading mode, depth and output limits, and stable references for acting on elements. Scoped snapshots fetch a smaller DOM when Chrome supports it. Annotated screenshots can omit unchanged images.

The built-in agent guide now loads advanced topics on demand with `better-playwriter skill --ref`.
